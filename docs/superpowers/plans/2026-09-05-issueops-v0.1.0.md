# IssueOps v0.1.0 전환 계획

**승인 범위:** 프로젝트·GitHub 저장소·CLI·설치·상태·스킬 이름 전체 전환. 전환 완료 버전은 v0.1.0이다. 사용자는 구 이름의 별칭과 호환 코드를 남기지 않는 전환을 명시했다.

**구조:** Go core와 얇은 호스트 adapter는 유지한다. 정식 명령 issueops와 단축 명령 io가 같은 바이너리를 실행한다. lifecycle 명령은 기존 provenance·generation·CWD 검사를 거쳐 최상위에서 실행한다. 작업 상태는 status, 설치 종합 상태는 system-status다.

- [x] CLI·Go module/import·bin·MCP·환경변수·문서·SQLite·daemon 이름을 통일한다.
- [x] 인물명 스킬 13개와 업데이트 스킬을 역할명으로 바꾸고 caller·schema·UI metadata·테스트를 맞춘다.
- [x] 기존 이름의 runtime reader와 alias를 제거한다. 이전 도구와 원본 백업은 제품 밖의 private 위치에 둔다.
- [x] 두 독립 사전 리뷰의 command guard·기록·설치 이전 지적을 반영한다. 최종 독립 리뷰에서 발견한 완료 flag 불일치를 수정한다.
- [x] 새 HOME에서 native 설치와 형식·Python·명령 경로·계약 검증을 수행한다.
- [x] 최종 full/race/lint/self-verify와 문서 검사 결과를 확정한다. self-verify 26/26 통과, 최저 목표 점수 100.
- [ ] 검증한 커밋을 main에 통합하고 source/state/native 설치를 이전한다.
- [ ] GitHub 저장소·origin·v0.1.0 태그·Release를 전환하고 원격 결과를 확인한다.

**데이터 원칙:** ID와 schema_version을 유지한다. 지원하지 않는 활성 lease·pending intent·동시 writer는 이전을 거부한다. 새 binary가 이전 후 기록을 읽는지 검사한다. 과거 benchmark의 이름 치환본은 원본 커밋·manifest SHA를 기록한 파생 metadata이며 새 실행 결과가 아니다.

**검증:** Go 전체·race·vet·CI 고정 lint, CLI/MCP golden과 conformance, skill validators, Python tests, 347개 이상의 문서 링크, native fresh install, private migration test 15개, installed io/issueops의 명령·MCP·daemon readback.

**위임:** devils-advocate-review/fresh_review로 사전 및 최종 리뷰를 격리한다. task-fan-out-coordination/context_isolation으로 스킬 metadata 14개와 private 이전 도구만 파일 소유권을 나눠 처리했다. 교차 구조·실제 데이터 이전·통합·게시 판단은 메인이 소유한다.
