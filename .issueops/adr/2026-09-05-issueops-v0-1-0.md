# IssueOps v0.1.0 이름 전환

- Date: 2026-09-05
- Kind: `adr`
- Source: cli
- Summary: 사용자 승인에 따라 프로젝트·저장소·실행 파일은 IssueOps/issueops, 단축 명령은 io로 통일한다. lifecycle 명령은 최상위로 옮기고 설치 종합 상태는 system-status로 분리한다. 스킬은 인물명 대신 역할명을 사용한다. .issueops, ISSUEOPS_ 환경변수, issueops MCP와 SQLite·daemon 이름을 사용하며 구 이름 별칭이나 읽기 호환 코드는 남기지 않는다. 기존 설치·상태는 private 백업 후 일회성 도구로 이전하며 도구는 배포 소스에 포함하지 않는다. 과거 벤치마크 이름 치환본에는 원본 커밋·manifest SHA와 metadata-only 표시를 남기고 새 실행으로 주장하지 않는다. 데이터 schema_version과 제품 v0.1.0은 별개이며 원격 기존 태그는 보존한 뒤 전환 완료 커밋으로 재지정한다.
